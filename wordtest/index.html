단어시험 생성기

조교쌤용 사용 가이드
  1. 학교 · 학년을 고릅니다.
  2. 시험 범위를 클릭해서 고릅니다. 첫 범위를 누르고 마지막 범위를 Shift+클릭하면 사이가 한 번에 선택됩니다.
  3. 문항 수
    • 보통 시험에서는 단어 개수를 100으로 지정합니다.
    • 출제 가능 단어가 80개 미만이면 출제 가능한 단어 개수를 모두 출제합니다.
    • 범위를 고르면 문항 수가 자동으로 맞춰지므로(80개 이상 → 100, 80개 미만 → 전부) 따로 고칠 필요가 없습니다.
  4. 출제 방식(영어 → 뜻 / 뜻 → 영어 / 섞어서)을 고릅니다.
  5. 인쇄 매수에 학생 수만큼 입력합니다. 시험지를 다르게 나눠야 할 때만 ‘서로 다른 시험지’를 2 이상으로 바꿉니다.
  6. 새 시험지 만들기 → 인쇄하기를 누르면 인쇄 창이 뜹니다. 정답지는 맨 뒤에 있습니다.
